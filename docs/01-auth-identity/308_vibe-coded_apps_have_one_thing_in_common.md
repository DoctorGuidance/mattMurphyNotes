## 🎧 ۵. متن کامل ترنسکریپت زبان اصلی (Original Audio Transcript)
<div dir="ltr">

Vibe-coded apps have one thing in common. The auth is broken. 

People can see each other’s data. Sessions don’t expire. And the developer doesn’t know because they only tested with one account. 

The fix: 

1. Never roll your own — use Clerk, Supabase Auth, or Auth0. Battle-tested > homegrown. 

2. Test the logout — log in, copy URL, log out, paste it back. If it loads, you have no auth. 

3. Row-level security — every query filters by user ID. 

No exceptions. Ever. 

Auth is not a feature. It’s the foundation. 

-MM
